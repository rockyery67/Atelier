# UI/UX demo captures

Captured on **24 October 2026** from the connected physical **2201117TG** Android
phone, running Atelier **1.0.0** (version code 1). Original PNGs are **1080 × 2400**,
captured directly with Android `screencap`. No mockups, compositing, recoloring,
replacement text or generated screens are used. README image widths only scale
their display; the linked PNGs retain the original resolution.

The gallery uses handwriting and Full motion, with Warm daylight and Evening
desk captured separately. Phone preferences were restored afterward to Follow
device, Clean print enabled, Minimal motion and the original keep-awake setting
(0). The app was left on Home. No reviews were rated, no new items were saved,
and no reminders were created or notification permissions changed for these
captures. Existing sample content and counts reflect this install's saved state.

The reminder image intentionally retains the visible notifications-off state.
Its picker values are an unsaved draft, not evidence of an active alert. Device
timezone was UTC+05:45. Earlier delivery/performance checks remain separately
documented in [verification](../VERIFICATION.md); this capture pass does not
repeat those checks or establish animation/audio quality from static images.
